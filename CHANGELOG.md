# Changelog

## 0.3.0 — Public release preparation

- Bundled the original MIT-licensed Layer Tower STL and its generator.
- Added format parser checks and a documented compatibility matrix.
- Added discoverable 3MF/STL naming, a release guide and an explicit source package list.
- Report unsupported files found in dropped folders.
- Retained nested folder categories and click-outside dismissal of project details.


## 0.2.0 — LayerLibrary

- Named the app LayerLibrary and added About, privacy information, and MIT licensing.
- Added explicit Add/Replace import choices and keep-both/replace/skip path conflicts.
- Added transactional imports, progress, cancellation, and error reports.
- Added name, size, date, and format sorting.
- Added named exports, size estimates, and whole-library/category/filtered scopes.
- Separated maintainable source from generated single-HTML releases.
- Added regression tests and a public build that embeds no third-party models.

Existing features include folder categories, search, pagination, 3D previews, memory-only thumbnails, duplicate detection, and confirmed original-file deletion where supported.
