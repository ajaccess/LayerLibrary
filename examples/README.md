# Layer Tower

An original demonstration model created for LayerLibrary. It is a small, solid stepped tower with a flat base: 32 × 32 × 21 mm, 512 triangles, about 26 KB.

The model and its generator (`scripts/make_sample.py`) are covered by the project's MIT license. You may use, modify, redistribute, and sell them while retaining the license notice. No external models, logos, or downloaded designs were used.

Regenerate with `python3 scripts/make_sample.py`. The default public build embeds this STL and includes a standalone copy in the ZIP. The in-app picture is rendered from the mesh in memory; no image asset or internet connection is needed.

STL does not encode units; use millimetres if opening it in a slicer. This is a demonstration, not a calibrated printer test or a claim of tested print settings.
